# 🔄 Setup App - ETL & Data Migration Engine

## 🎯 **Overview**

The **Setup App** is a comprehensive **ETL (Extract, Transform, Load) and data migration engine** that transforms customer acquisition by making it effortless to switch from any Greek or international ERP system to our platform. This eliminates the biggest barrier to adoption and creates a significant competitive advantage in the Greek market.

## 🛠️ **Technical Stack**

### **Frontend**

- **Framework**: Next.js 15 + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **State Management**: Zustand for migration state
- **Real-time Updates**: WebSocket for progress tracking

### **Backend**

- **Migration Engine**: Node.js with TypeScript
- **Database**: PostgreSQL with migration schemas
- **Queue System**: Redis for background processing
- **File Processing**: Multer for file uploads

### **Greek Integration**

- **Data Validation**: Greek business format validation
